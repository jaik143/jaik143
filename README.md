## How I work

- Infrastructure defined in code and versioned, never clicked together in a console.
- Pipelines that build, scan, push and deploy without a human in the middle.
- Security checks (SAST, image scanning, least-privilege IAM) inside the pipeline rather than after it.
- Multi-AZ and autoscaling by default, so a single failure is not an outage.
